# Password Strength Checker 🔐

A Python-based cybersecurity project that evaluates password strength based on multiple security requirements.

## Features

The program checks for:

- At least 8 characters
- Numbers
- Uppercase letters
- Lowercase letters
- Symbols

The password is then classified as:

- Weak
- Medium
- Strong
